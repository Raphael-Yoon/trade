# 📊 월별 자산 및 배당금 현금흐름 보고서 (Asset Report Module)

커피하우스 시스템 본체(`trade.py`)와 완전히 분리된 **독립형 월별 자산 및 배당금 프레젠테이션 생성 모듈**입니다.

---

## 🎯 특징
1. **커피하우스 본체 무영향**: 커피하우스 웹 서버나 코드를 전혀 건드리지 않고, `trade.db`를 오직 **읽기 전용(Read-Only)**으로만 참조합니다.
2. **그때그때 실행하는 월별 스냅샷**: 매월 말이나 배당 발표 시점에 단 1회 명령어를 실행하여 해당 월의 16:9 프레젠테이션 파일(`asset_report_YYYY_MM.html`)을 생성합니다.
3. **16:9 와이드 프레젠테이션 덱**:
   - 키보드 방향키(`←`/`→`), 스페이스바로 넘기는 파워포인트 슬라이드 모드
   - `Ctrl + P` 한 번으로 **16:9 규격의 고해상도 발표용 PDF**로 분할 출력 지원
   - 세후(15% 미국 원천세 공제 통장 입금액) ⇄ 세전 총액 원클릭 인터랙티브 전환
   - 환율 민감도 매트릭스 및 실생활 지출 커버리지 분석 내장

---

## 🚀 사용법

### 1. 이번 달 보고서 즉시 생성
```bash
cd trade/asset_report
./run.sh
```

### 2. 특정 월 지정 생성
```bash
cd trade/asset_report
./run.sh --month 2026-10
```

### 3. 생성 결과물 확인
생성된 보고서는 `outputs/` 폴더에 월별로 아카이빙됩니다.
- 예: `trade/asset_report/outputs/asset_report_2026_10.html`
- 웹 브라우저(크롬 등)로 더블 클릭하여 즉시 실행하시면 됩니다.
